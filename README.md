# Terminal Coding Agent

An end-to-end autonomous AI coding agent built from scratch in Python.

## Goals

- Build a production-quality terminal coding assistant.
- Support multiple LLM providers.
- Edit files safely.
- Execute shell commands.
- Plan multi-step coding tasks.
- Run tests and fix errors autonomously.
- Maintain conversation and workspace memory.

## Tech Stack

- Python 3.12
- uv
- Typer
- Rich
- Pydantic
- OpenAI SDK
